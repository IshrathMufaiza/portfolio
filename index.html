01 / HOUSEHOLD APP

GharSaathi

A household companion project designed to help individuals and families organize groceries and everyday tasks. The current prototype includes authentication and grocery-list functionality, with additional household and AI features planned.

ReactNode.jsExpress.jsMongoDBJWT
Source Code

01 / The spark

The idea is to make everyday household organization easier for individuals and families, bringing grocery lists and tasks into one place.

02 / The challenge

Build a useful household app while connecting the interface, user authentication and saved grocery data into one working flow.

03 / The build

The current prototype uses React on the frontend, with Node.js and Express.js on the backend, MongoDB for data storage, and JWT-based authentication. Household sharing and additional AI features remain part of the broader project plan.

04 / The takeaway

This project brings together frontend development, API-backed functionality, authentication and persistent data in a single application.

A work in progress — the story will grow as the project does.
02 / DEVELOPER TOOL

GitHub Repository Analyzer

A developer-focused web tool that turns GitHub repository information into a cleaner, more useful view. It highlights API-driven frontend work and an emphasis on developer-oriented UX.

JavaScriptWeb APIsGitHubResponsive UI
Live Demo

01 / The spark

The goal is to turn GitHub repository information into a clearer, more useful view for developers.

02 / The challenge

Working with GitHub data also means accounting for API rate limits, so repeated requests need to be handled thoughtfully.

03 / The build

The project combines a JavaScript-based interface with GitHub API data. A caching approach helps reduce repeated requests and manage rate-limit constraints.

04 / The takeaway

The project highlights the importance of designing around external API constraints as well as presenting the returned data in a useful interface.
